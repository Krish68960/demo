DEMO SYSTEM

A new request starts as PENDING_APPROVAL .

The administrator has 60 seconds to approve it.

After approval, the trade becomes ACTIVE for 60 seconds.

If the administrator selects WIN or LOSS, that result is stored but the user will NOT see the result until the 60-second trade timer expires.

If the administrator does not select a result, the system automatically generates a simulated result when the timer expires.

This system is for demonstration only and does not execute real trades or transfer real money.
